# Domain Knowledge Index

This folder contains business domain documentation for the behaviour the library ships. Each file covers a specific business area. A consumer product adds its own files to its own repository and indexes them the same way.

**How to use:**
Before working in any domain area, find the relevant file in the table below.

| File | Domain | Key Topics | Relevant Projects |
|------|--------|------------|-------------------|
| [user-accounts.md](user-accounts.md) | User Accounts | Registration, Sign-in, Sign-out, Password Policy | HopeTech.Common |
| [user-permissions.md](user-permissions.md) | Administration | Role-Based Access Control, Role Assignment | HopeTech.Common |
