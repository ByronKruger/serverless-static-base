# coffeeg-web

Angular 22 client for Coffeeg. See `AGENTS.md` in this folder for the workspace map and
the conventions, `../../Docs/ARCHITECTURE.md` for the rules, and `../../README.md` for how
to run the API alongside it.

```bash
npm start          # dev server on :4200, /api proxied to https://localhost:7011
npm run build      # production build into dist/
npm test           # component tests
```
